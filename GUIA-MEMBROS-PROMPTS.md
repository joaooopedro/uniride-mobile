## 1. Passo a Passo Rápido para Cada Membro

1. **Aceitar o convite do repositório**: Acesse [joaooopedro/uniride-mobile/invitations](https://github.com/joaooopedro/uniride-mobile) ou seu e-mail do GitHub.
2. **Clonar o projeto**:
   ```bash
   git clone https://github.com/joaooopedro/uniride-mobile.git
   cd uniride-mobile
   npm install
   ```
3. **Criar a sua branch de trabalho**:
   ```bash
   git checkout -b feature/nome-da-sua-tarefa
   ```
4. **Abrir na sua IDE com IA**: (Cursor, VS Code com Claude Code / Cline / Copilot / Gemini / Windsurf).
5. **Executar a Tarefa com a IA**:
   - Copie o **Prompt Mestre de Sistema (Bloco A)**.
   - Copie o **Prompt da sua Tarefa Específica (Bloco B)**.
   - Envie para o seu agente de IA.
6. **Testar no Expo Go**:
   ```bash
   npx expo start
   ```
   Abra o app Expo Go no celular (Android ou iOS) ou emulador e confira a tela e navegação.
7. **Commitar e Enviar**:
   ```bash
   git add .
   git commit -m "feat(modulo): implementa descricao da sua tarefa"
   git push origin feature/nome-da-sua-tarefa
   ```
8. **Abrir Pull Request** no GitHub vinculando o número da sua Issue (ex: `Resolves #3`).

## 2. Prompt Mestre de Sistema (Copiar e colar antes da task)

```text
Você é um desenvolvedor especialista em React Native, Expo e Styled Components trabalhando no aplicativo móvel UniRide (Carona Universitária Solidária) da UniAcademia.

=== DIRETRIZES TÉCNICAS E ARQUITETURA ===
1. Stack: React Native (Expo SDK 51+), @react-navigation/drawer, @react-navigation/bottom-tabs, @react-navigation/native-stack, styled-components/native.
2. Estilização: Use SEMPRE styled-components/native consumindo o tema centralizado em `src/theme/index.js` (cores primárias #2563EB, fundo #F8FAFC, cartões #FFFFFF, texto principal #0F172A, texto secundário #64748B, sucesso #10B981, alerta #F59E0B, bordas #E2E8F0).
3. Componentização: Escreva código modular, limpo, responsivo e sem warnings. Todos os inputs devem ter feedback visual, validação amigável e acessibilidade.
4. Dados Mockados: Utilize dados realistas do contexto universitário da UniAcademia em Juiz de Fora - MG (Campi: Campus Academia / Centro e Campus Estrela Sul; Bairros: Cascatinha, São Mateus, Alto dos Passos, Santa Luzia, Granbery, Benfica, Centro, Manoel Honório).
5. Estado: Consuma e atualize o contexto global `src/context/CaronasContext.js` para persistência em memória de caronas, reservas e perfil.

=== REGRA RÍGIDA DE GIT E AUTORIA ===
- NUNCA inclua linhas de co-autoria de IA (como 'Co-authored-by: Claude', 'Co-authored-by: Copilot', 'Co-authored-by: Cursor', etc.) nem mensagens 'Generated by AI' em commits, documentação ou pull requests.
- Toda autoria de código e commit pertence exclusivamente ao desenvolvedor humano responsável pela tarefa.
- Gere código pronto para produção, sem placeholders incompletos ou 'TODOs' vazios.
```
