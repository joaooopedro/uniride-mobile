# Manual de uso do UniRide

Cada seção é escrita por quem fez as telas, com prints em `img/` (nome do arquivo começando pelo número da seção, como `02-oferecer-cep.png`). A ordem segue o uso do app, do primeiro acesso à avaliação.

| Seção | Conteúdo | Responsável |
|---|---|---|
| [1. Acesso e busca](01-acesso-e-busca.md) | instalar, criar conta, confirmar e-mail, entrar, recuperar senha, buscar e filtrar caronas, mapa | Caio Castilho |
| [2. Motorista](02-motorista.md) | virar motorista, oferecer carona (CEP, mapa, feriado, valor), rascunho, aceitar e recusar, iniciar, concluir e cancelar | Gabriel Caputo |
| [3. Detalhes, avaliação e perfil](03-detalhes-avaliacao-perfil.md) | detalhes com mapa e clima, pedir e cancelar vaga, contato, avaliar, avaliações e selos, perfil, trocar de modo, sair | Nicolas Isaac |
| [4. Chat e reservas](04-chat-e-reservas.md) | minhas reservas e status, conversa, avisos rápidos | Jonathan Delmonte |
| [5. Avisos no celular](05-avisos.md) | permissão, quais avisos chegam, aviso fixo da próxima carona | João Pedro |

Para o PDF do AVA: juntar as seções nesta ordem, com capa e sumário.
